# إعداد قاعدة البيانات (Supabase) — خطوة بخطوة

المدة: نحو 10 دقائق. لا تحتاج أي برمجة.

## 1) إنشاء المشروع
1. ادخل إلى supabase.com وسجّل بحساب جديد (مجاني).
2. اضغط **New project**، واختر اسماً (مثل `nexus`) وكلمة مرور قوية للقاعدة **واحتفظ بها**.
3. اختر أقرب منطقة (مثلاً Frankfurt أو Bahrain إن ظهرت)، ثم انتظر دقيقتين حتى يكتمل الإنشاء.

## 2) تشغيل المخطط
1. من القائمة اليسرى: **SQL Editor** ثم **New query**.
2. افتح ملف `nexus/supabase/migrations/001_schema.sql` من المستودع، وانسخ **كل** محتواه والصقه، ثم **Run**.
3. المتوقع: رسالة `Success. No rows returned`. إن ظهر خطأ فلا تُعد التشغيل، وأرسل لي نصه كما هو.
   (التشغيل مرة ثانية على نفس المشروع يعطي خطأ "already exists"، وهذا طبيعي ولا يضر.)

## 3) السماح بالدخول التلقائي (وضع الاختبار)
**Authentication ← Sign In / Providers ← Allow anonymous sign-ins** فعّلها.

## 4) أخذ مفتاحين فقط
**Project Settings ← API**، ثم أرسل لي:
- **Project URL**
- **anon public key**

⚠️ لا ترسل `service_role` أبداً، ولا كلمة مرور القاعدة. المفتاحان أعلاه مصمَّمان ليظهرا في المتصفح، وأمانهما يعتمد على قواعد RLS التي في المخطط.

## 5) قبل الإنتاج (لا تنسَ)
وضع الدخول المفتوح يجعل **أي شخص يفتح الرابط** مديراً يرى البيانات ويستوردها. شغّل هذا السطر في SQL Editor لإيقافه:

```sql
update public.system_settings set value = 'false' where key = 'open_guest_mode';
```

وبعد إيقافه يحتاج كل مستخدم حساباً: أنشئه من **Authentication ← Users ← Add user**، ثم اربطه:

```sql
-- مدير
insert into public.profiles (user_id, role) values ('<معرّف المستخدم>', 'admin');
-- مندوب: الاسم يجب أن يطابق اسمه في دفترة حرفياً
insert into public.profiles (user_id, role, rep_name) values ('<معرّف المستخدم>', 'rep', 'اسم المندوب');
```
معرّف المستخدم يظهر في صفحة Users (عمود UID).

## 6) كيف تتأكد أن كل شيء سليم
- **Table Editor** يجب أن يعرض الجداول: `sales`, `payments`, `rep_settings`, `targets`, `import_log`, `system_settings`, `profiles`.
- بعد أول استيراد: عدد صفوف `sales` يساوي ما أظهرته المعاينة، وإعادة استيراد الملف نفسه لا تزيده.

## النسخ الاحتياطي
الخطة المجانية لا تتيح نسخاً يومياً قابلاً للتنزيل. سأضيف زر **تصدير كل البيانات** للمدير في المرحلة الأخيرة، ويُنصح باستخدامه أسبوعياً.
