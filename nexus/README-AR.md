# NEXUS Dashboard — دليل التشغيل

نظام يعمل كاملاً داخل **ملف HTML واحد**: لا خادم ولا حساب ولا اشتراك. يستورد تقارير دفترة، ويحفظها في متصفحك، ويعرض المؤشرات والقوائم.

## الملفان
| الملف | الاستعمال |
|---|---|
| `nexus-empty.html` | نظام فارغ. تستورد فيه ملفاتك بنفسك. |
| `nexus-real.html` | نفس النظام ببياناتك محمّلة عند أول فتح (يحوي بيانات حساسة؛ لا ترفعه على موقع عام). |

## التشغيل (دقيقتان)
1. احفظ الملف على جهازك وافتحه بـ **Chrome** (نقرتان).
2. اضغط **استيراد ملفات دفترة**، واختر معاً: تقرير الفواتير، وتقرير المدفوعات، وحساب الأستاذ العام (اختياري).
3. راجع المعاينة: يجب أن ترى ✓ بجانب كل ملف («يطابق صف الإجمالي الكلي ومجاميع المناديب»). ثم **حفظ في النظام**.
4. حدّد **الفترة** و**المناديب/المناطق/المناصب** من الأعلى. كل الأرقام تتغير معاً.

إعادة استيراد نفس الملف آمنة: لا تتكرر الفواتير (يظهر «أُضيف 0 — حُدّث N»). ولاستيراد فترة جديدة اختر ملفات تلك الفترة؛ يُضاف الجديد ويُحدَّث الموجود.

## التبويبات
- **ملخص الأداء:** البطاقات، الرسمان، وجدول المناديب مع تحقيق الأهداف.
- **أكبر العملاء مدينية:** الرصيد الصافي وأعمار الدين (حتى تاريخ «إلى»).
- **الفواتير / السندات (بيانات خام):** بحث وتصدير Excel أو CSV.
- **التحقق:** مطابقة مع الأستاذ العام، و«مقارنة مع أرقام دفترة» (أدخل أرقام دفترة الرسمية وسترى الفروق).

## الأهداف والإعدادات
- **الأهداف:** شهرياً لكل مندوب (مبيعات وتحصيل). هدف المنطقة والشركة = مجموع المناديب المتضمَّنين في الفلتر. الشريط يتوقف عند 100% ويصير ذهبياً عند التجاوز.
- **الإعدادات:** المنطقة والمنصب لكل مندوب (نص حر)، اسم النظام والشعار، **نسخة احتياطية**.
- افتراضات يمكنك تغييرها: هدف التحصيل يقارَن بـ«إجمالي المقبوضات»؛ الشهر الجزئي يُحتسب هدفه كاملاً؛ الأسبوع يبدأ الأحد (`WEEK_START` في `src/kpi.js`).

## النسخ الاحتياطي (مهم)
البيانات تُحفظ **في متصفحك على هذا الجهاز فقط**. إن مسحت بيانات المتصفح ضاعت.
- **الإعدادات ← تصدير كل البيانات (JSON)**: افعل ذلك أسبوعياً واحفظ الملف.
- **الإعدادات ← استرجاع من نسخة**: يعيد الفواتير والسندات والأهداف والإعدادات.

## كيف تتأكد أنك تستعمل أحدث نسخة
الشارة بجانب اسم النظام تعرض الإصدار (مثل `1.0.0-single-file`). إن أرسلتُ لك نسخة جديدة فاستبدل الملف القديم وتأكد أن الرقم تغيّر.

## الأمان
- النظام لا يحتاج إنترنت ولا يرسل بياناتك لأي جهة.
- **ليس فيه تسجيل دخول ولا صلاحيات**: من يفتح الملف على جهازك يرى كل شيء. لعرض المندوب بياناته فقط يلزم خادم (انظر `supabase/SETUP-AR.md`، وهو جاهز ومُختبَر).

## الاختبار (للمطوّر)
```
npm install
npm test                                   # اختبارات المنطق وقاعدة Postgres
NEXUS_SAMPLES_DIR=/مسار/الملفات npm test   # + اختبارات على ملفاتك الحقيقية
npm run verify /مسار/الملفات               # جدول PASS/FAIL لكل مطابقة، ورمز خروج 1 عند أي فرق
```
بناء الملف الواحد:
```
node scripts/make-demo-data.mjs /مسار/الملفات seed.json
node scripts/build-demo.mjs nexus-real.html seed.json     # ببياناتك
node scripts/build-demo.mjs nexus-empty.html              # فارغ
```
